# 信号词典与扣分标准

## 使用方法

逐条扫描 JD 原文（深解档还需扫联网检索到的公司信息），命中即记录到 hidden_signals。
风险分从 100 起扣，细则见 output-schema 打分模型。

## 红灯（每条 -15 ~ -25，按严重度取值）

| 信号 | 扣分 | 说明 |
|---|---|---|
| 狼性 / 奋斗者 / 家文化 / 军事化管理 | -25 | 高压 + 边界感差 |
| 吃苦耐劳 / 不计较个人得失 | -20 | 薪资与工作量不匹配的前置合理化 |
| 薪资显著低于城市/级别行情（L3 核实后） | -20 | 诚意不足 |
| 资深头衔 + 初级职责（总监岗干执行活） | -20 | 职级虚高，谈薪与背调有坑 |
| 挂录 >3 个月且仍在活跃刷新 | -15 | 流动性高或要求离谱 |
| 公司近 6 个月裁员/欠薪新闻（L3） | -25 | 一票否决候选 |
| 「能接受高强度工作」+ 边缘业务线 | -20 | 双重风险叠加 |

## 黄灯（每条 -5 ~ -10）

| 信号 | 扣分 |
|---|---|
| 抗压 / 快节奏 / 弹性工作 | -10 |
| 年轻化 / 有活力 | -10（大龄候选人按红处理） |
| 降本增效 / 精细化运营 | -10 |
| 从 0 到 1 | -5（与机会分对冲） |
| 独立负责、无支持表述 | -5 |
| 跨部门推动 | -5；出现 ≥3 次升为 -10 |
| 汇报线未披露 | -5 |
| 薪资未披露 | -5 |

## 绿灯（不加分，作为岗位质量的加分证据）

- 职责与要求互相呼应
- 写明汇报线与团队规模
- 薪资带宽清晰且中位接近市场 P50
- 写出具体技术栈与方法论
- 提及导师制 / 成长路径
- JD 带个性细节（业务方亲写的证据）

## 一票否决识别

满足任一条，决策卡 `veto` 字段非空，直接输出「不投（门槛）」，总分仅作参考：

1. **硬门槛不可弥补**：学历/年限/执照等硬性条件不满足，且经历中无等效替代路径。
   注意：可包装 ≠ 造假——packagable 指换一种表述命中关键词，不是编造经历。
2. **个人约束冲突**：用户明示的不可接受项被命中（如「不接受 996」+ 确证大小周）。
3. **公司存续风险**（L3 确证）：欠薪、裁员进行中、劳资纠纷集中。

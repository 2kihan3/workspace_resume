# 面试官信号词典

> 所有信号结论必须能指回本词典条目，引用格式 §节号。

## 使用方法

逐条扫描逐字稿，**重点扫描收尾 10-15 分钟与反问环节**（信号最密集区）。命中即记录
到 `signals`，标注时间戳或 Q 编号。单个信号不作结论——信号面打分看整体分布。

## 积极信号（绿灯）

| 信号 | 解读 |
|---|---|
| 主动介绍团队构成/业务规划/日常工作 | 面试官在「卖」岗位 = 对你有意向 |
| 详聊薪资结构/期权/调薪机制 | 已把你放进可发 offer 的心理账户 |
| 问到岗时间/离职流程/竞业限制 | 在评估落地速度 |
| 面试超时（超出预定 15 分钟以上） | 聊得投入 |
| 主动安排或提及下一轮/加面/引荐同事 | 流程推进的明确信号 |
| 反问环节回答认真且有信息量（讲了团队方向、业务挑战） | 愿意花时间建立互信 |
| 询问工作内容偏好/团队选择等软性问题 | 在为你做安置匹配 |
| 结束语具体（「一周内 HR 联系你」） | 对比：「有消息会通知你」 |

## 消极信号（红灯）

| 信号 | 解读 |
|---|---|
| 提前结束（明显低于预定时长且无外部打断） | 兴趣不足 |
| 对同一短板换角度反复确认（≥3 次） | 疑虑未消，这是拒信最常见的来源 |
| 质疑经历真实性（「这个数据是你做的吗」） | 高危：真实性防御失败的直接证据 |
| 反问环节敷衍（「都写在 JD 里了」） | 不愿投入 |
| 提及「还有其他候选人要对比」 | 概率话术 |
| 全程无任何岗位相关的深挖问题 | 走过场 |
| 对转行/跳槽动机追问且不接受解释 | 动机疑虑，短期难扭转 |

## 中性信号（黄灯，信息性）

- 流程性回答（「后续统一安排」）——无信息量，不作判断依据
- 面试官中途处理其他事务——取决于后续是否回到深挖
- 面试官记录很多——中性偏积极（在认真评估）

## 轮次修正（同一信号在不同轮次含义不同）

- 聊薪资：HR 面/终面出现=正常推进；技术一面出现=积极信号
- 问离职动机：每轮都问=正常；同一轮反复问=消极
- 安排加面：技术面后=正常流程；老板面后仍加面=可能在比较候选人
- 自述文档输入：信号面天然缺失，不做信号推断，标 N/A

## 疑虑地图构建

追问链聚类 → 每个疑虑条目：

```text
话题（如「电商经验不足」）
追问次数（该话题被追问的轮数）
防御结果：稳（答住了）/ 勉强（绕过去了）/ 崩（露怯或自相矛盾）
建议补法：感谢信主动补 / 下一轮开场先说 / 长期补齐
```

规则：
- 追问次数 ≥2 或防御为「崩」的疑虑必须进 follow-up-email.md 的补坑清单
- 防御为「崩」且属硬门槛话题的疑虑，同时进下一场准备清单
- 疑虑话题与 jd-analyst requirements 的 R 编号对得上时，标注关联

# 评分规则

## 六维打分（各 0-100，加权求和）

**内容质量（25%）**：专业深度、案例具体性、数字与细节的使用。
- 90+：核心问题答出深度且有可验证细节，追问越挖越有货
- 70-89：内容对且有细节，但个别问题平淡
- 50-69：多数回答停在概念层，缺案例或数字
- <50：大量「差不多」「应该可以」级回答

**表达质量（15%）**：结论先行、简洁度、时长控制。
- 90+：先结论后展开，2-3 分钟收住，重点突出
- 70-89：偶有铺垫过长但能收
- 50-69：经常绕、需要面试官打断引导
- <50：答非所问或絮叨到失控

**匹配度呈现（20%）**：与岗位最相关的经历是否讲到了显眼位置。
- 90+：主动把 JD 核心关注对应到自己最强的证据上
- 70-89：被问到才展开，未主动引导
- 50-69：相关经历被埋没在其他内容里
- <50：全程未呈现与岗位的关联

**真实性防御（20%）**：被追问后的稳定性。
- 90+：所有追问答得住，数字经得起「怎么算的」
- 70-89：个别追问绕过但未露怯
- 50-69：有明显回避或前后口径不一
- <50：出现自相矛盾或承认说不清自己简历里的内容

**反问质量（10%）**：反问是否体现思考。
- 90+：问业务挑战/团队协作/成长路径，且基于面试中听到的信息
- 70-89：问了正经问题但通用
- 50：只问加班/薪资/福利
- 0：没反问（自述文档输入标 N/A）

**信号面（10%）**：信号词典红绿灯汇总。
- 绿灯为主、无红灯 = 85+；混合 = 50-84；红灯 ≥2 或含真实性质疑 = <50
- 自述文档输入标 N/A

## N/A 归一化

自述文档输入时「反问质量」「信号面」为 N/A，权重在剩余四维间等比放大
（内容 36% / 表达 21% / 匹配 29% / 防御 29% 四舍五入近似）。
逐字稿与音频输入不适用 N/A。

## 逐题分级标准

| 级别 | 标准 |
|---|---|
| 讲透了 | 结构完整（结论先行或 STAR 完整）+ 有数字或细节 + 追问稳 |
| 合格 | 结构完整或内容对，但平淡（无细节或无亮点） |
| 含糊 | 没结论、过于抽象、被追问后开始绕 |
| 崩了 | 答非所问、自相矛盾、或承认不了解且无补救思路 |

**归因分离**（含糊/崩了的题必填）：

| 归因 | 判据 | 行动 |
|---|---|---|
| 没准备 | 内容其实有，现场没组织好 | 重答清单速补，收益最快 |
| 没经验 | 该领域确实空白 | 长期补齐或调整岗位预期 |
| 表达问题 | 有货倒不出（絮叨/跑偏） | 练结构化表达，限时限次练习 |
| 非必要 | 超纲偏题且低频出现 | 记录但不投入，标注「非必要」 |

## 通过预判（verdict）

| 档位 | 规则 |
|---|---|
| 稳 | 总分 ≥75 且无红灯 |
| 五五开 | 总分 50-74；或 ≥75 但有 1 个红灯 |
| 悬 | 总分 <50；或红灯 ≥2；或出现真实性被质疑的红灯（直接判悬） |

**预判置信度**：
- 高：信号丰富且方向一致（≥4 个信号且无矛盾）
- 中：信号混合或偏少
- 低：材料不足（自述文档、短材料、转写质量差）——自述文档输入的
  verdict_confidence 上限为「中」

预判是推断不是结果，报告必须附 `verdict_evidence`（依据信号清单），并提示：
「无论预判如何，重答清单与下一场准备独立生效」。

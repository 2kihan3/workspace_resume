# 求职工作台 · 安装与试用说明

本地优先的 macOS 求职管理桌面应用：岗位看板、JD 分析、简历排版、投递跟进，数据全部保存在你自己电脑上。

## 安装（macOS，Apple Silicon）

1. 下载最新版 `求职工作台_x.x.x_aarch64.dmg`
2. 双击打开 dmg，把「求职工作台」拖进「Applications」（应用程序）文件夹
3. **首次打开**：在应用程序文件夹里**右键点图标 → 打开 → 再点"打开"**
   （应用没有 Apple 商店签名，这是 macOS 对所有非商店软件的要求，只需一次）
   - 如果右键打开仍提示"已损坏"：打开"终端"（聚焦搜索 Terminal），粘贴下面这行回车，再双击即可：
     ```bash
     xattr -cr /Applications/求职工作台.app
     ```
4. Intel 芯片的 Mac 暂未提供安装包（可联系作者）

## 两种使用模式

### 模式 A：开箱即用（无需任何配置）

岗位库、求职看板、简历库（导入/编辑/排版/导出 PDF）、沟通与面试跟进——这些功能完全本地运行，装好就能用。

### 模式 B：AI 能力（需要一点环境，建议找技术朋友花 10 分钟）

JD 智能分析、公司调研、岗位定制简历需要本机的 Codex 环境：

```bash
# 1) 安装 Node.js（https://nodejs.org，LTS 版）
# 2) 安装 codex CLI
npm install -g @openai/codex
# 3) 登录（浏览器完成）
codex login
```

然后在应用的「设置」页点"启动 / 连接"，看到你的账号信息即配置成功。

> 隐私：除你主动触发的 AI 任务（JD/简历内容发给本机 Codex 进程）外，应用不联网、不上传任何数据。

## 常见问题

- **数据存在哪？** `~/Library/Application Support/com.jobdesk.workbench/`，卸载应用不会删数据
- **怎么备份？** 设置页 → 创建备份（生成 .jsw-backup 文件，可恢复）
- **AI 任务跑多久？** JD 分析通常 1–3 分钟；公司调研需要联网，可能 3–5 分钟，期间别关应用
- **AI 报错"未找到 codex"？** 按上面模式 B 步骤安装，或设置页确认 CLI 路径
